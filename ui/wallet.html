从零开始本地试签

在自己的电脑上安装 Git、Node.js 22 或更高版本和 Foundry，然后在终端运行以下命令。

git clone https://github.com/AURVENwallet/AURVEN.git
cd AURVEN
node scripts/local-wallet.mjs

打开终端显示的本机地址，设置演示密码并配对账户。按 Ctrl+C 可结束本次演示。
